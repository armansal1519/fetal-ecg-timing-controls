# Within-site constant-offset sensitivity

This exploratory sensitivity was specified after scoring the global +2 ms control. On each Polish B2 recording in turn, fit one site offset using only the other eleven recordings. Use all valid fetal beats, apply the same ordered one-to-one 50 ms fitter as the global control, take the clipped (±28 ms) median of the eleven recording-level signed reference-minus-native medians, and shift all native calls on the omitted recording. Save the twelve offsets, training IDs, predicted streams and mask checks. Report equally recording-weighted estimates against native Power and both frozen projected models. Folds share training data, so do not attach a population confidence interval to these differences. A separate display shows native predictions shifted by each of five fixed values (−4, −2, 0, +2, +4 ms) on the same twelve recordings. Do not select an operating point from that grid. This design uses labels from the same instrument, site and study as its evaluation and cannot serve as independent confirmation.
